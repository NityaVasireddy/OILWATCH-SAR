# Limitations
- SAR dark spots have non-oil look-alikes.
- The supplied dataset is limited and domain-specific.
- Segmentation errors propagate into geometry and drift.
- The drift model is simplified and environmentally uncertain.
- AIS can contain gaps, errors or spoofing and only represents transmitting vessels.
- Geographic coordinates require valid geospatial metadata in the SAR input.
- Release time is uncertain.
- Vessel correlation is an investigation lead, not proof of responsibility.
